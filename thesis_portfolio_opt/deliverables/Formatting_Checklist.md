# Thesis Formatting Checklist

Use this checklist before submitting the next thesis draft.

## Text Layout

- Paragraphs are justified.
- Page numbers are enabled and placed according to the university template.
- Chapter, section, and subsection numbering follows the template.
- Font family, font size, margins, and line spacing follow the template.
- The first page, title page, abstract, table of contents, list of figures, and list of tables follow the template.
- `Thesis_Format_Template.tex` provides a local LaTeX shell for justified text, page numbering, captions, margins, table of contents, list of tables, and list of figures.
- `Thesis_Draft_Formatted.docx` is generated by `export_thesis_docx.py` with justified body paragraphs, page numbers, margins, headings, lists, and markdown tables.

## Figures and Tables

- Every figure has a numbered caption in the required position.
- Every table has a numbered caption in the required position.
- Figure and table labels are referenced in the text before or near the object.
- Table styling is consistent: no raw notebook-style output, no oversized columns, no broken line wrapping.
- Figures are exported at thesis quality and not pasted as low-resolution screenshots.

## Chapter-Level Content

- Introduction includes problem definition, motivation, scope, assumptions, limitations, short definitions, contributions, and thesis structure.
- Literature review includes background theory for Markowitz mean-variance optimization, dynamic portfolio optimization, macro factor models, ML return prediction, CVXPY, LightGBM, autonomous search, swarm intelligence, and MiroFish.
- Methodology explains each system stage separately: AutoResearch, MiroFish, integrated pipeline, reporting, and feedback loop.
- Results clearly distinguish economic performance from statistical significance.

## Final Consistency

- Terminology is consistent: AutoResearch, MiroFish, ML-only, ML+Swarm, Swarm-only, OOS.
- Transaction cost assumptions are consistently written as 3 bps and 10 bps.
- Main OOS period is consistently written as 2022--2024.
- Claims in the text match the generated tables and figures.
